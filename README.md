# Servicio de catéteres PICC

Página informativa en español sobre el servicio de catéteres PICC y el dispositivo PowerPICC.

La página principal está en `index.html`. Los estilos se editan en `src/scss/app.scss` y la versión servida por GitHub Pages está en `build/css/app.css`. Para regenerarla con las dependencias instaladas, ejecuta `npx gulp css`.

El sitio no muestra un canal de contacto porque aún no se proporcionó uno. Las imágenes clínicas son ilustrativas; confirma las características del producto con la [información del fabricante](https://www.bd.com/en-us/products-and-solutions/products/product-families/powerpicc-catheter).
